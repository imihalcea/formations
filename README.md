# Formations

| Formation | Répertoire | Label | État |
|---|---|---|---|
| Claude Code et Open Code en ligne de commande | `claude-code/` | `claude-code` | finition |
| Développement logiciel assisté par l'IA | `dlaia/` | `dlaia` | refonte en cours |
| DLAIA Avancé (module complémentaire facultatif) | `dlaia-avance/` | `dlaia-avance` | démarrage |

Chaque répertoire contient le support en Markdown (`support/`), le projet fil rouge, les corrigés des TP (`tp/`), les notes de préparation (`formateur/`) et l'application qui compile le support (`template-support/app/`). Le support compilé est un fichier `dist/index.html` autosuffisant, qui s'ouvre sans serveur.
