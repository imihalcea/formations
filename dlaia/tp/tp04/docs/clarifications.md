# Réponses du responsable produit

Réponses aux questions de `clarify` sur le brouillon ; elles priment sur l'option recommandée.

1. Bornes (30 min, 4 h, 8h00, 20h00, 2 h, 60 jours) : incluses, la valeur pile est acceptée.
2. Plusieurs règles enfreintes : un seul code, celui de la première dans l'ordre REG-01 à REG-05.
3. Dépendance au temps : la décision dépend du seul instant courant fourni en entrée.
4. Jours fériés : ouvrés, aucune exception.
5. Fuseau horaire : un seul, local, aucune conversion.
6. Quota par demandeur : hors périmètre.
7. Annulation : hors périmètre.
8. Pools de ressources : hors périmètre, la ressource visée existe.
9. Approbation d'une réservation : hors périmètre.
10. API et stockage : inchangés.
